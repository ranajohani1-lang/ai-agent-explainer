# How an AI Agent Plans Your Day

An interactive web page that explains how an AI agent works, for people who know nothing about agents.

The page follows an agent as it plans a one-day trip in New York City. Click **Next** to see each stage:

**Goal → Plan → Act → Check → Fix → Result**

In the Check stage, the agent finds that a coffee shop on the plan is closed. In the Fix stage, it picks a new coffee shop and checks the plan again.

## How it was made

This page was built with an AI agent (Claude) for a class assignment on using agentic systems. I gave the agent this prompt:

> Build an interactive web page that explains how an AI agent works, for people who know nothing about agents. Use simple English.
>
> Show an agent planning a one-day trip in New York, step by step. The user clicks "Next" to see each stage: Goal → Plan → Act → Check → Fix → Result.
>
> In the Check stage, the agent finds that a coffee shop on the plan is closed. In the Fix stage, it picks a different coffee shop and updates the plan.
>
> At each stage, show a short explanation of what the agent is doing and why.
